How Likely Is Each Word to Be Drawn?

Compare two or more words, e.g. GREENLET GREENLIT, and the table shows the number of ways to draw each rack from a full bag with 0, 1, or 2 blanks. The totals row shows the full number of ways to draw the tiles. Click "relative" to normalize so the least likely word becomes 100%, making it easy to compare the others against it.

Try comparing ANEROID and TRAINEE — with no blanks TRAINEE is more likely, but once blanks are possible ANEROID wins. Or try ISOLATE and INERTIA: they're very close with blanks but about 10% apart with none.
