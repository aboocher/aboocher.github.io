G4: Unit Circle Trigonometry

27 practice problems, roughly ordered from warm-up to challenge within each topic. Work the problems first, then check the Solutions section below.

  • The unit circle has radius $1$. For an angle $\theta$ in standard position (vertex at the origin, initial side along the positive $x$-axis), the terminal ray meets the circle at the point $(\cos\theta, \sin\theta)$.
  • The reference angle is the acute angle between the terminal ray and the $x$-axis. Find it first, then attach the correct sign for the quadrant.
  • ASTC ("All Students Take Calculus"): QI all six functions positive, QII sine (and cosecant) positive, QIII tangent (and cotangent) positive, QIV cosine (and secant) positive — everything else in each quadrant is negative.
  • $\sec\theta=\dfrac{1}{\cos\theta}$, $\csc\theta=\dfrac{1}{\sin\theta}$, $\cot\theta=\dfrac{1}{\tan\theta}$ — undefined wherever the denominator is $0$.
  • Exact values must be left as fractions/radicals with rationalized denominators — never decimals.
  • Two special-triangle ratios generate every coordinate on the circle: $1:1:\sqrt2$ (legs equal) and $1:\sqrt3:2$ (short leg, long leg, hypotenuse) — here scaled to hypotenuse $1$.

Solutions

Reference Angles & Quadrant Signs

1.

$\theta=\frac{5\pi}{6}$ is in QII, just short of $\pi=\frac{6\pi}{6}$.

Reference angle $= \pi - \frac{5\pi}{6} = \frac{\pi}{6}$.

↑ problem
2.

$\theta=\frac{7\pi}{4}$ is in QIV, just short of $2\pi=\frac{8\pi}{4}$.

Reference angle $= 2\pi - \frac{7\pi}{4} = \frac{\pi}{4}$.

↑ problem
3.

$\theta=\frac{4\pi}{3}$ is in QIII, just past $\pi=\frac{3\pi}{3}$.

Reference angle $= \frac{4\pi}{3} - \pi = \frac{\pi}{3}$.

↑ problem
4.

$\frac{5\pi}{3} = \frac{10\pi}{6}$ lies between $\frac{3\pi}{2}=\frac{9\pi}{6}$ and $2\pi=\frac{12\pi}{6}$, so it's in QIV.

In QIV: $\sin\theta$ is negative, $\cos\theta$ is positive.

↑ problem
5.

$\frac{2\pi}{3}$ lies between $\frac{\pi}{2}$ and $\pi$, so it's in QII.

In QII, sine is positive and cosine is negative, so $\tan\theta = \frac{\sin\theta}{\cos\theta}$ is negative. $\sec\theta = \frac{1}{\cos\theta}$ is also negative.

↑ problem
6.

$\frac{7\pi}{6}$ is in QIII, where both sine and cosine are negative.

Negative $\times$ negative $=$ positive, so $\sin\left(\frac{7\pi}{6}\right)\cos\left(\frac{7\pi}{6}\right)$ is positive.

↑ problem

25.

$\sin^2\theta+\cos^2\theta=1 \Rightarrow \cos^2\theta = 1-\frac14=\frac34 \Rightarrow \cos\theta=\pm\dfrac{\sqrt3}{2}$. In QIII, cosine is negative, so $\cos\theta=-\dfrac{\sqrt3}{2}$.

$\tan\theta = \dfrac{\sin\theta}{\cos\theta} = \dfrac{-1/2}{-\sqrt3/2} = \dfrac{1}{\sqrt3}=\dfrac{\sqrt3}{3}$

↑ problem
26.

$\sin^2\theta = 1-\cos^2\theta = 1-\frac12=\frac12 \Rightarrow \sin\theta=\pm\dfrac{\sqrt2}{2}$. In QIV, sine is negative, so $\sin\theta=-\dfrac{\sqrt2}{2}$.

$\sec\theta = \dfrac{1}{\cos\theta} = \dfrac{1}{\sqrt2/2} = \dfrac{2}{\sqrt2}=\sqrt2$

↑ problem
27.

$h=\sin\left(\frac{2\pi}{3}\right) = \dfrac{\sqrt3}{2} \approx 0.87$.

Since $h>0$, the rider is above the center.
