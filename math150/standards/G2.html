G2: Linear Equations — Slope, Intercepts & Graphing

23 practice problems, roughly ordered from warm-up to challenge within each topic. Work the problems first, then check the Solutions section below.

  • Convert to slope-intercept form ($y = mx + b$) to read off the slope and $y$-intercept directly.
  • To find intercepts algebraically: set $y=0$ to find the $x$-intercept, and set $x=0$ to find the $y$-intercept.
  • Parallel lines have the same slope. Perpendicular lines have slopes that are negative reciprocals (they multiply to $-1$).
  • When you have a point and a slope, use point-slope form: $y - y_1 = m(x - x_1)$.
  • Vertical lines ($x = a$) and horizontal lines ($y = b$) are special cases — don't forget them.

Applications of Linear Functions

18.

The candle starts at 20 cm ($y$-intercept) and loses 2.5 cm per hour (slope): $h(t) = 20 - 2.5t$.

The slope $-2.5$ means the height decreases by 2.5 cm every hour.

$h(6) = 20 - 2.5(6) = 20 - 15 = 5$ cm

↑ problem
19.

Base fee is the $y$-intercept, per-mile rate is the slope: $C(m) = 1.75m + 3$.

$C(8) = 1.75(8) + 3 = 14 + 3 = 17$ — the ride costs $\$17$.

↑ problem
20.

$C(t) = 25t + 60$.

Set $C(t) = 310$: $25t + 60 = 310 \Rightarrow 25t = 250 \Rightarrow t = 10$ months.

↑ problem
21.

$C(x) = 0.10x + 20$.

Set $C(x) = 35.50$: $0.10x + 20 = 35.50 \Rightarrow 0.10x = 15.50 \Rightarrow x = 155$ extra texts.

22.

Slope: $m = \dfrac{200 - 380}{5 - 2} = \dfrac{-180}{3} = -60$ gallons/hour.

Using $(2, 380)$: $g - 380 = -60(t - 2) \Rightarrow g = -60t + 500$.

(Check: at $t=0$, $g=500$ — matches the tank's full capacity.)

Empty when $g = 0$: $-60t + 500 = 0 \Rightarrow t = \dfrac{500}{60} = \dfrac{25}{3} \approx 8.33$ hours.

23.

Slope: $m = \dfrac{270 - 450}{3 - 0} = \dfrac{-180}{3} = -60$ dollars/year.

$(0, 450)$ is the $y$-intercept: $V(t) = 450 - 60t$.

$V(5) = 450 - 60(5) = 450 - 300 = 150$ — worth $\$150$ after 5 years.
