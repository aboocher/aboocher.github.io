I7: Integration by u-Substitution

24 practice problems on u-substitution — recognizing an integrand as $f(g(x))\cdot g'(x)$, then integrating in terms of $u$.

  • The pattern: if you can spot an "inner function" $g(x)$ and its derivative $g'(x)$ sitting right next to it (up to a constant multiple), let $u=g(x)$, $du=g'(x)\,dx$, and rewrite the whole integral in terms of $u$.
  • After integrating in terms of $u$, always substitute back so the final answer is in terms of $x$ — except in the bounds trick below.
  • Definite integrals: you can change the bounds to $u$-values right when you substitute (evaluate $g$ at the old limits), and then skip converting back to $x$ at the end.
  • If your candidate $du$ is off by a constant factor from what's in the integral, that's fine — solve for $dx$ in terms of $du$ and pull the constant out front.
  • Always check your work by differentiating your final antiderivative — the chain rule should hand you back the original integrand.

Polynomial Power u-Substitution

1.

Let $u=x^4+1$, so $du=4x^3\,dx$ — that's exactly what's left over.

$\displaystyle\int u^5\,du=\frac{u^6}{6}+C=\frac{(x^4+1)^6}{6}+C$

↑ problem
2.

Let $u=x^2-3$, so $du=2x\,dx$.

$\displaystyle\int u^4\,du=\frac{u^5}{5}+C=\frac{(x^2-3)^5}{5}+C$

↑ problem
3.

Let $u=x^3+5$, so $du=3x^2\,dx$, meaning $6x^2\,dx=2\,du$.

$\displaystyle\int 2u^3\,du=\frac{2u^4}{4}+C=\frac{(x^3+5)^4}{2}+C$

↑ problem
4.

Let $u=x^5-2$, so $du=5x^4\,dx$.

$\displaystyle\int u^2\,du=\frac{u^3}{3}+C=\frac{(x^5-2)^3}{3}+C$

↑ problem
5.

Let $u=x^2+3x$, so $du=(2x+3)\,dx$ — the whole first factor.

$\displaystyle\int u^4\,du=\frac{u^5}{5}+C=\frac{(x^2+3x)^5}{5}+C$

↑ problem
6.

Let $u=x^3+1$, so $du=3x^2\,dx$. Write $\sqrt{x^3+1}=u^{1/2}$.

$\displaystyle\int u^{1/2}\,du=\frac{2}{3}u^{3/2}+C=\frac{2}{3}(x^3+1)^{3/2}+C$

Trigonometric u-Substitution

7.

Let $u=\sin x$, so $du=\cos x\,dx$.

$\displaystyle\int u^2\,du=\frac{u^3}{3}+C=\frac{\sin^3 x}{3}+C$

↑ problem
8.

Let $u=\cos x$, so $du=-\sin x\,dx$, meaning $\sin x\,dx=-du$.

$\displaystyle\int -u^2\,du=-\frac{u^3}{3}+C=-\frac{\cos^3 x}{3}+C$

↑ problem
9.

Let $u=\tan x$, so $du=\sec^2x\,dx$.

$\displaystyle\int u^3\,du=\frac{u^4}{4}+C=\frac{\tan^4 x}{4}+C$

↑ problem
10.

Let $u=3x$, so $du=3\,dx$, meaning $dx=\frac{1}{3}du$.

$\displaystyle\frac13\int \sin u\,du=-\frac13\cos u+C=-\frac13\cos(3x)+C$

↑ problem
11.

Let $u=x^2$, so $du=2x\,dx$, meaning $x\,dx=\frac12du$.

$\displaystyle\frac12\int \sin u\,du=-\frac12\cos u+C=-\frac12\cos(x^2)+C$

↑ problem
12.

Let $u=4x$, so $du=4\,dx$, meaning $dx=\frac14du$.

$\displaystyle\frac14\int \cos u\,du=\frac14\sin u+C=\frac14\sin(4x)+C$

Exponential and Logarithmic u-Substitution

13.

Let $u=x^2$, so $du=2x\,dx$, meaning $x\,dx=\frac12du$.

$\displaystyle\frac12\int e^u\,du=\frac12e^u+C=\frac12e^{x^2}+C$

↑ problem
14.

Let $u=3x$, so $du=3\,dx$, meaning $dx=\frac13du$.

$\displaystyle\frac13\int e^u\,du=\frac13e^u+C=\frac13e^{3x}+C$

↑ problem
15.

Let $u=\ln x$, so $du=\frac1x\,dx$ — exactly the rest of the integrand.

$\displaystyle\int u^2\,du=\frac{u^3}{3}+C=\frac{(\ln x)^3}{3}+C$

↑ problem
16.

Let $u=\ln x$, so $du=\frac1x\,dx$.

$\displaystyle\int \frac{1}{u}\,du=\ln|u|+C=\ln|\ln x|+C$

↑ problem
17.

Let $u=x^3$, so $du=3x^2\,dx$, meaning $x^2\,dx=\frac13du$.

$\displaystyle\frac13\int e^u\,du=\frac13e^u+C=\frac13e^{x^3}+C$

↑ problem
18.

Let $u=1+e^x$, so $du=e^x\,dx$ — exactly the numerator.

$\displaystyle\int \frac{1}{u}\,du=\ln|u|+C=\ln(1+e^x)+C$

(No absolute value needed — $1+e^x$ is always positive.)

↑ problem

Definite Integrals — Changing the Bounds

19.

Let $u=\sin x$, so $du=\cos x\,dx$. When $x=0$, $u=0$; when $x=\pi/2$, $u=1$.

$\displaystyle\int_0^1 u^2\,du=\left[\frac{u^3}{3}\right]_0^1=\frac13-0=\frac13$

↑ problem
20.

Let $u=x^2+1$, so $du=2x\,dx$, meaning $x\,dx=\frac12du$. When $x=0$, $u=1$; when $x=1$, $u=2$.

$\displaystyle\frac12\int_1^2 u^3\,du=\frac12\left[\frac{u^4}{4}\right]_1^2=\frac12\left(4-\frac14\right)=\frac12\cdot\frac{15}{4}=\frac{15}{8}$

↑ problem
21.

Let $u=1+e^x$, so $du=e^x\,dx$. When $x=0$, $u=2$; when $x=\ln 2$, $u=3$.

$\displaystyle\int_2^3 \frac{1}{u}\,du=\left[\ln u\right]_2^3=\ln 3-\ln 2=\ln\frac32$

↑ problem
22.

Let $u=\ln x$, so $du=\frac1x\,dx$. When $x=1$, $u=0$; when $x=e$, $u=1$.

$\displaystyle\int_0^1 u\,du=\left[\frac{u^2}{2}\right]_0^1=\frac12-0=\frac12$

↑ problem
23.

Let $u=\tan x$, so $du=\sec^2x\,dx$. When $x=0$, $u=0$; when $x=\pi/4$, $u=1$.

$\displaystyle\int_0^1 u\,du=\left[\frac{u^2}{2}\right]_0^1=\frac12-0=\frac12$

↑ problem
24.

Let $u=x^3+1$, so $du=3x^2\,dx$, meaning $x^2\,dx=\frac13du$. When $x=0$, $u=1$; when $x=1$, $u=2$.

$\displaystyle\frac13\int_1^2 u^2\,du=\frac13\left[\frac{u^3}{3}\right]_1^2=\frac13\left(\frac83-\frac13\right)=\frac13\cdot\frac73=\frac{7}{9}$
