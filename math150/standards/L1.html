L1: Evaluating Limits Graphically

28 practice problems built around four graphs, grouped from warm-up to challenge. For each graph you're asked to read off one-sided limits, the two-sided limit, and the function value at specific $x$-values — no algebra required, just careful graph reading.

  • $\displaystyle\lim_{x\to a^-}f(x)$ means "the height the graph approaches as $x$ gets close to $a$ from the left."
  • $\displaystyle\lim_{x\to a^+}f(x)$ means the same thing from the right.
  • The two-sided limit $\displaystyle\lim_{x\to a}f(x)$ exists only when the left- and right-hand limits are equal. If they disagree, the limit does not exist (DNE).
  • A limit describes what height the graph is approaching, not what happens exactly at $x=a$ — an open circle (a hole) never stops a limit from existing.
  • $f(a)$ is the actual $y$-value plotted at $x=a$: look for a filled dot. If there's no filled dot at $x=a$, then $f(a)$ is undefined.
  • Watch for graphs where a hole and a separate filled dot don't line up — the limit and $f(a)$ can be two different numbers at the same $x$.
  • A jump (the graph "steps" to a new height) means the one-sided limits disagree, so the two-sided limit does not exist even though each one-sided limit exists on its own.

Warm-Up: A Continuous Graph

The graph has a corner at $(-1,1)$, but both pieces meet there at the same height — it's continuous, just not smooth.

1.

Following the left piece toward $x=-1$, the graph rises to a height of $1$.

$\displaystyle\lim_{x\to -1^-}f(x)=1$

↑ problem
2.

Following the right piece back toward $x=-1$, the graph also comes from a height of $1$.

$\displaystyle\lim_{x\to -1^+}f(x)=1$

↑ problem
3.

The left- and right-hand limits agree ($1=1$), so the two-sided limit exists and equals that common value.

$\displaystyle\lim_{x\to -1}f(x)=1$

↑ problem
4.

The graph actually passes through the point $(-1,1)$, so the function value matches the limit here.

$f(-1)=1$

↑ problem

Jump Discontinuities

At both $x=-2$ and $x=2$ the graph "steps" to a new height, so the two-sided limit fails to exist at each — but for a different reason each time when it comes to $f(a)$.

5.

The left piece ends at a filled dot at height $-1$ as $x\to -2^-$.

$\displaystyle\lim_{x\to -2^-}f(x)=-1$

↑ problem
6.

The middle piece starts at an open dot at height $-3$ as $x\to -2^+$.

$\displaystyle\lim_{x\to -2^+}f(x)=-3$

↑ problem
7.

The one-sided limits disagree ($-1\ne -3$), so the two-sided limit does not exist.

$\displaystyle\lim_{x\to -2}f(x)=\text{DNE}$

↑ problem
8.

The filled dot at $x=-2$ sits at height $-1$ (it belongs to the left piece).

$f(-2)=-1$

↑ problem
9.

The middle piece ends at an open dot at height $1$ as $x\to 2^-$.

$\displaystyle\lim_{x\to 2^-}f(x)=1$

↑ problem
10.

The right piece starts at a filled dot at height $3$ as $x\to 2^+$.

$\displaystyle\lim_{x\to 2^+}f(x)=3$

↑ problem
11.

The one-sided limits disagree ($1\ne 3$), so the two-sided limit does not exist.

$\displaystyle\lim_{x\to 2}f(x)=\text{DNE}$

↑ problem
12.

The filled dot at $x=2$ sits at height $3$ (it belongs to the right piece).

$f(2)=3$

↑ problem

Removable Discontinuities (Holes)

This graph is a single straight line with two points punched out of it — one left truly undefined, one relocated elsewhere. In both cases the limit only cares about the line, never about the missing or moved point.

13.

Following the line toward $x=-1$ from the left, the height approaches $0$.

$\displaystyle\lim_{x\to -1^-}f(x)=0$

↑ problem
14.

Following the same line from the right, the height also approaches $0$.

$\displaystyle\lim_{x\to -1^+}f(x)=0$

↑ problem
15.

Both one-sided limits agree, so the two-sided limit exists — the open circle (hole) doesn't change what height the line is approaching.

$\displaystyle\lim_{x\to -1}f(x)=0$

↑ problem
16.

There is no filled dot anywhere above or below $x=-1$ — the hole is never filled in.

$f(-1)$ is undefined

↑ problem
17.

Following the line toward $x=2$ from the left, the height approaches $3$.

$\displaystyle\lim_{x\to 2^-}f(x)=3$

↑ problem
18.

Following the same line from the right, the height also approaches $3$.

$\displaystyle\lim_{x\to 2^+}f(x)=3$

↑ problem
19.

Both one-sided limits agree, so the two-sided limit exists.

$\displaystyle\lim_{x\to 2}f(x)=3$

↑ problem
20.

The line has an open hole at $x=2$, but a separate filled dot is drawn below it at height $-2$. That relocated dot is the function value — and it does not match the limit found in #19.

$f(2)=-2$

Putting It Together

One jump discontinuity and one ordinary continuous point, on the same graph.

21.

The left piece ends at a filled dot at height $2$ as $x\to -2^-$.

$\displaystyle\lim_{x\to -2^-}f(x)=2$

↑ problem
22.

The right piece starts at an open dot at height $-2$ as $x\to -2^+$.

$\displaystyle\lim_{x\to -2^+}f(x)=-2$

↑ problem
23.

The one-sided limits disagree ($2\ne -2$), so the two-sided limit does not exist.

$\displaystyle\lim_{x\to -2}f(x)=\text{DNE}$

↑ problem
24.

The filled dot at $x=-2$ sits at height $2$ (it belongs to the left piece).

$f(-2)=2$

↑ problem
25.

$x=3$ is an ordinary point in the middle of the right piece (no break there). Reading the height from the left gives $3$.

$\displaystyle\lim_{x\to 3^-}f(x)=3$

↑ problem
26.

Reading the height from the right gives the same value, since the graph is one unbroken line through this region.

$\displaystyle\lim_{x\to 3^+}f(x)=3$

↑ problem
27.

The one-sided limits agree, so the two-sided limit exists.

$\displaystyle\lim_{x\to 3}f(x)=3$

↑ problem
28.

The graph actually passes through $(3,3)$ — at a continuous point, the function value always matches the limit.

$f(3)=3$
