G3: Right Triangle Trigonometry

30 practice problems, roughly ordered from warm-up to challenge within each topic. Work the problems first, then check the Solutions section below.

  • SOH-CAH-TOA, relative to the reference angle $\theta$: $\sin\theta = \dfrac{\text{opp}}{\text{hyp}}$, $\cos\theta = \dfrac{\text{adj}}{\text{hyp}}$, $\tan\theta = \dfrac{\text{opp}}{\text{adj}}$.
  • Use the Pythagorean theorem ($a^2+b^2=c^2$) to find a missing side once you know the other two.
  • A $45$-$45$-$90$ triangle has side ratio $1 : 1 : \sqrt2$ (leg : leg : hypotenuse).
  • A $30$-$60$-$90$ triangle has side ratio $1 : \sqrt3 : 2$ (short leg : long leg : hypotenuse).
  • Exact values must be left as fractions/radicals — never round to a decimal.
  • Rationalize denominators that contain a radical, e.g. write $\dfrac{1}{\sqrt3}$ as $\dfrac{\sqrt3}{3}$.

Solutions

Trig Ratios from a Right Triangle

1.

Relative to $\theta$: opposite $= 3$, adjacent $= 4$, hypotenuse $= 5$.

$\sin\theta = \frac{3}{5}$, $\cos\theta = \frac{4}{5}$, $\tan\theta = \frac{3}{4}$

↑ problem
2.

Relative to $\theta$: opposite $= 12$, adjacent $= 5$, hypotenuse $= 13$.

$\sin\theta = \frac{12}{13}$, $\cos\theta = \frac{5}{13}$, $\tan\theta = \frac{12}{5}$

↑ problem
3.

Relative to $\theta$: opposite $= 15$, adjacent $= 8$, hypotenuse $= 17$.

$\sin\theta = \frac{15}{17}$, $\cos\theta = \frac{8}{17}$, $\tan\theta = \frac{15}{8}$

↑ problem
4.

$\sin\theta = \frac{5}{13}$ means opposite $=5$, hypotenuse $=13$. The missing leg is $\sqrt{13^2-5^2} = \sqrt{169-25}=\sqrt{144}=12$.

$\cos\theta = \frac{12}{13}$, $\tan\theta = \frac{5}{12}$

↑ problem
5.

$\cos\theta = \frac{7}{25}$ means adjacent $=7$, hypotenuse $=25$. The missing leg is $\sqrt{25^2-7^2} = \sqrt{625-49}=\sqrt{576}=24$.

$\sin\theta = \frac{24}{25}$, $\tan\theta = \frac{24}{7}$

↑ problem
6.

$\tan\theta = \frac{3}{4}$ means opposite $=3$, adjacent $=4$. The hypotenuse is $\sqrt{3^2+4^2} = \sqrt{25} = 5$.

$\sin\theta = \frac{3}{5}$, $\cos\theta = \frac{4}{5}$

↑ problem

Special Right Triangles

10.

In a $45$-$45$-$90$ triangle the legs are equal.

Other leg $= 6$. Hypotenuse $= 6\sqrt2$.

↑ problem
11.

Leg $= \dfrac{\text{hyp}}{\sqrt2} = \dfrac{10}{\sqrt2} = \dfrac{10\sqrt2}{2} = 5\sqrt2$.

Each leg $= 5\sqrt2$.

↑ problem
12.

Short leg $=7$. Using the ratio $1:\sqrt3:2$: long leg $= 7\sqrt3$, hypotenuse $= 2(7) = 14$.

↑ problem
13.

Hypotenuse $=20$, so short leg $= \dfrac{20}{2} = 10$, and long leg $= 10\sqrt3$.

↑ problem
14.

Long leg $= 9 = \text{short leg}\cdot\sqrt3$, so short leg $= \dfrac{9}{\sqrt3} = \dfrac{9\sqrt3}{3} = 3\sqrt3$.

Hypotenuse $= 2(3\sqrt3) = 6\sqrt3$.

↑ problem
15.

(a) $\theta=\frac{\pi}{6}$: opposite $= 12\sin\frac{\pi}{6} = 12\cdot\frac12 = 6$; adjacent $= 12\cos\frac{\pi}{6} = 12\cdot\frac{\sqrt3}{2}=6\sqrt3$.

(b) $\theta=\frac{\pi}{4}$: both legs $= 12\sin\frac{\pi}{4} = 12\cdot\frac{\sqrt2}{2} = 6\sqrt2$.

(c) $\theta=\frac{\pi}{3}$: opposite $= 12\sin\frac{\pi}{3} = 12\cdot\frac{\sqrt3}{2}=6\sqrt3$; adjacent $= 12\cos\frac{\pi}{3} = 12\cdot\frac12 = 6$.

θ = π/4
θ = π/3

Applications

27.

Height up the wall (opposite) $= 10\sin(60°) = 10\cdot\dfrac{\sqrt3}{2} = 5\sqrt3$ ft.

Distance from wall (adjacent) $= 10\cos(60°) = 10\cdot\dfrac12 = 5$ ft.

↑ problem
28.

Height (opposite) $= 40\sin(60°) = 40\cdot\dfrac{\sqrt3}{2} = 20\sqrt3$ m.

Horizontal distance (adjacent) $= 40\cos(60°) = 40\cdot\dfrac12 = 20$ m.

↑ problem
29.

The $20$ m distance is adjacent to the $45°$ angle of elevation; the height is opposite.

Height $= 20\tan(45°) = 20(1) = 20$ m.

↑ problem
30.

The $18$ ft distance is adjacent to the $30°$ angle; the rise is opposite, and the ramp length is the hypotenuse.

Rise $= 18\tan(30°) = 18\cdot\dfrac{\sqrt3}{3} = 6\sqrt3$ ft.

Ramp length $= \dfrac{18}{\cos(30°)} = \dfrac{18}{\frac{\sqrt3}{2}} = \dfrac{36}{\sqrt3} = 12\sqrt3$ ft.
