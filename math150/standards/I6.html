I6: The Fundamental Theorem of Calculus

18 practice problems evaluating definite integrals with the Fundamental Theorem of Calculus.

  • FTC: $\displaystyle\int_a^b f(x)\,dx=F(b)-F(a)$, where $F$ is any antiderivative of $f$. Find the antiderivative first (no $+C$ needed for a definite integral — it cancels), then evaluate at the top bound minus the bottom bound.
  • Notation: $\big[F(x)\big]_a^b$ means $F(b)-F(a)$ — write out both evaluations before subtracting so a sign error doesn't creep in.
  • If the integrand isn't already a sum of clean power/trig/exponential terms, simplify first — split a fraction into pieces, expand a product, or rewrite a root as a fractional exponent — exactly like in I2, just now with bounds attached.
  • A definite integral is a number, not a function — the final answer should have no $x$ left in it.

Solutions

Power Rule Definite Integrals

1.

$\displaystyle\int_1^3 x^2\,dx=\left[\frac{x^3}{3}\right]_1^3=\frac{27}{3}-\frac13=9-\frac13=\frac{26}{3}$

↑ problem
2.

$\displaystyle\int_0^2 (3x^2-2x)\,dx=\left[x^3-x^2\right]_0^2=(8-4)-(0-0)=4$

↑ problem
3.

$\displaystyle\int_{-1}^2 (x^2+1)\,dx=\left[\frac{x^3}{3}+x\right]_{-1}^2=\left(\frac83+2\right)-\left(-\frac13-1\right)=\frac{14}{3}-\left(-\frac43\right)=\frac{18}{3}=6$

↑ problem
4.

$\displaystyle\int_1^4 \sqrt{x}\,dx=\left[\frac23x^{3/2}\right]_1^4=\frac23(8)-\frac23(1)=\frac{16}{3}-\frac23=\frac{14}{3}$

↑ problem
5.

Expand first: $(x-2)^2=x^2-4x+4$.

$\displaystyle\int_0^3 (x^2-4x+4)\,dx=\left[\frac{x^3}{3}-2x^2+4x\right]_0^3=(9-18+12)-0=3$

↑ problem
6.

$\displaystyle\int_{-2}^1 (4-x^2)\,dx=\left[4x-\frac{x^3}{3}\right]_{-2}^1=\left(4-\frac13\right)-\left(-8+\frac83\right)=\frac{11}{3}-\left(-\frac{16}{3}\right)=\frac{27}{3}=9$

↑ problem

Trig and Exponential Definite Integrals

7.

$\displaystyle\int_0^{\pi/4} \sec^2 x\,dx=\big[\tan x\big]_0^{\pi/4}=\tan\frac{\pi}{4}-\tan 0=1-0=1$

↑ problem
8.

$\displaystyle\int_0^{\pi/2} \cos x\,dx=\big[\sin x\big]_0^{\pi/2}=1-0=1$

↑ problem
9.

$\displaystyle\int_0^{\pi} \sin x\,dx=\big[-\cos x\big]_0^{\pi}=(-\cos\pi)-(-\cos 0)=1-(-1)=2$

↑ problem
10.

$\displaystyle\int_0^1 e^x\,dx=\big[e^x\big]_0^1=e^1-e^0=e-1$

↑ problem
11.

$\displaystyle\int_{\pi/6}^{\pi/3} 2\cos x\,dx=\big[2\sin x\big]_{\pi/6}^{\pi/3}=2\sin\frac{\pi}{3}-2\sin\frac{\pi}{6}=2\cdot\frac{\sqrt3}{2}-2\cdot\frac12=\sqrt3-1$

↑ problem
12.

$\displaystyle\int_0^{\ln 2} e^x\,dx=\big[e^x\big]_0^{\ln 2}=e^{\ln 2}-e^0=2-1=1$

Needing Algebraic Simplification First

13.

$\displaystyle\frac{x-1}{\sqrt x}=x^{1/2}-x^{-1/2}$

$\displaystyle\int_1^4\left(x^{1/2}-x^{-1/2}\right)dx=\left[\frac23x^{3/2}-2x^{1/2}\right]_1^4=\left(\frac{16}{3}-4\right)-\left(\frac23-2\right)=\frac43-\left(-\frac43\right)=\frac83$

↑ problem
14.

$\displaystyle\frac{3x^2+2}{x}=3x+\frac2x$

$\displaystyle\int_1^2\left(3x+\frac2x\right)dx=\left[\frac32x^2+2\ln|x|\right]_1^2=(6+2\ln 2)-\left(\frac32+0\right)=\frac92+2\ln 2$

↑ problem
15.

$\displaystyle\frac{x^2-1}{\sqrt x}=x^{3/2}-x^{-1/2}$

$\displaystyle\int_1^4\left(x^{3/2}-x^{-1/2}\right)dx=\left[\frac25x^{5/2}-2x^{1/2}\right]_1^4=\left(\frac{64}{5}-4\right)-\left(\frac25-2\right)=\frac{44}{5}-\left(-\frac85\right)=\frac{52}{5}$

↑ problem
16.

$\displaystyle\frac{x^3-1}{x}=x^2-\frac1x$

$\displaystyle\int_1^2\left(x^2-\frac1x\right)dx=\left[\frac{x^3}{3}-\ln|x|\right]_1^2=\left(\frac83-\ln 2\right)-\left(\frac13-0\right)=\frac73-\ln 2$

↑ problem
17.

$\displaystyle\frac{\sqrt x+1}{\sqrt x}=1+x^{-1/2}$

$\displaystyle\int_4^9\left(1+x^{-1/2}\right)dx=\left[x+2x^{1/2}\right]_4^9=(9+6)-(4+4)=15-8=7$

↑ problem
18.

$\displaystyle\frac{x^2+2x}{x}=x+2$

$\displaystyle\int_1^3 (x+2)\,dx=\left[\frac{x^2}{2}+2x\right]_1^3=(4.5+6)-(0.5+2)=10.5-2.5=8$
