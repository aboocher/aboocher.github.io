A1: L'Hôpital's Rule with Justification

24 practice problems evaluating limits with L'Hôpital's Rule, covering every indeterminate form the rule applies to. For each one, justify the indeterminate form before differentiating — that check is part of the answer, not just the work.

  • L'Hôpital's Rule: if $\displaystyle\lim_{x\to a}\frac{f(x)}{g(x)}$ is $\frac{0}{0}$ or $\frac{\pm\infty}{\pm\infty}$, then $\displaystyle\lim_{x\to a}\frac{f(x)}{g(x)}=\lim_{x\to a}\frac{f'(x)}{g'(x)}$ — differentiate top and bottom separately (this is not the quotient rule).
  • Always state the indeterminate form first. If it isn't $\frac00$ or $\frac{\pm\infty}{\pm\infty}$, L'Hôpital doesn't apply and you need another method (or you're already done).
  • Sometimes one application isn't enough — if the new fraction is still indeterminate, check the form again and apply the rule again.
  • $0\cdot\infty$ forms: rewrite the product as a fraction — send one factor to the denominator as a reciprocal — to get $\frac00$ or $\frac{\infty}{\infty}$.
  • $\infty-\infty$ forms: combine the two pieces into a single fraction (common denominator) first — that turns it into $\frac00$.
  • Indeterminate powers ($1^\infty$, $0^0$, $\infty^0$): let $y$ equal the expression, take $\ln$ of both sides to bring the exponent down as a product, evaluate that $0\cdot\infty$ limit with L'Hôpital, then exponentiate ($e^{}$) to undo the log at the end.

Solutions

0/0 — Direct Application

1.

At $x=3$: $\frac{9-9}{9-9}=\frac00$. L'Hôpital applies.

$\displaystyle\lim_{x\to 3}\frac{x^2-9}{x^2-3x}=\lim_{x\to 3}\frac{2x}{2x-3}=\frac{6}{3}=2$

↑ problem
2.

At $x=2$: $\frac{0}{0}$. L'Hôpital applies.

$\displaystyle\lim_{x\to 2}\frac{x^3-8}{x^2-4}=\lim_{x\to 2}\frac{3x^2}{2x}=\frac{12}{4}=3$

↑ problem
3.

At $x=0$: $\frac{1-1}{0}=\frac00$. L'Hôpital applies.

$\displaystyle\lim_{x\to 0}\frac{e^{2x}-1}{x}=\lim_{x\to 0}\frac{2e^{2x}}{1}=2e^0=2$

↑ problem
4.

At $x=1$: $\frac{\ln 1}{0}=\frac00$. L'Hôpital applies.

$\displaystyle\lim_{x\to 1}\frac{\ln x}{x-1}=\lim_{x\to 1}\frac{1/x}{1}=\frac{1}{1}=1$

↑ problem

0/0 — Trig Limits (Sometimes More Than One Application)

5.

At $x=0$: $\frac{\sin 0}{0}=\frac00$. L'Hôpital applies.

$\displaystyle\lim_{x\to 0}\frac{\sin(5x)}{3x}=\lim_{x\to 0}\frac{5\cos(5x)}{3}=\frac{5}{3}$

↑ problem
6.

At $x=0$: $\frac{1-1}{0}=\frac00$. Apply L'Hôpital:

$\displaystyle\lim_{x\to 0}\frac{1-\cos x}{x^2}=\lim_{x\to 0}\frac{\sin x}{2x}$

Still $\frac00$ at $x=0$ — apply L'Hôpital again:

$\displaystyle=\lim_{x\to 0}\frac{\cos x}{2}=\frac{1}{2}$

↑ problem
7.

At $x=0$: $\frac{0-0}{0}=\frac00$. Apply L'Hôpital:

$\displaystyle\lim_{x\to 0}\frac{\tan x-x}{x^3}=\lim_{x\to 0}\frac{\sec^2 x-1}{3x^2}$

Still $\frac00$ — apply again:

$\displaystyle=\lim_{x\to 0}\frac{2\sec^2 x\tan x}{6x}$

Still $\frac00$ — apply a third time:

$\displaystyle=\lim_{x\to 0}\frac{2\left(2\sec^2x\tan^2x+\sec^4x\right)}{6}=\frac{2(0+1)}{6}=\frac{1}{3}$

↑ problem
8.

At $x=0$: $\frac{0-0}{0}=\frac00$. Apply L'Hôpital:

$\displaystyle\lim_{x\to 0}\frac{x-\sin x}{x^3}=\lim_{x\to 0}\frac{1-\cos x}{3x^2}$

Still $\frac00$ — apply again:

$\displaystyle=\lim_{x\to 0}\frac{\sin x}{6x}$

Still $\frac00$ — apply a third time:

$\displaystyle=\lim_{x\to 0}\frac{\cos x}{6}=\frac{1}{6}$

↑ problem

∞/∞ Forms

9.

As $x\to\infty$, both $\ln x\to\infty$ and $x^2\to\infty$: $\frac{\infty}{\infty}$. Apply L'Hôpital:

$\displaystyle\lim_{x\to \infty}\frac{\ln x}{x^2}=\lim_{x\to \infty}\frac{1/x}{2x}=\lim_{x\to \infty}\frac{1}{2x^2}=0$

↑ problem
10.

$\frac{\infty}{\infty}$. Apply L'Hôpital:

$\displaystyle\lim_{x\to \infty}\frac{\ln x}{\sqrt{x}}=\lim_{x\to \infty}\frac{1/x}{1/(2\sqrt{x})}=\lim_{x\to \infty}\frac{2\sqrt{x}}{x}=\lim_{x\to \infty}\frac{2}{\sqrt{x}}=0$

↑ problem
11.

$\frac{\infty}{\infty}$. Apply L'Hôpital:

$\displaystyle\lim_{x\to \infty}\frac{x^2}{e^x}=\lim_{x\to \infty}\frac{2x}{e^x}$

Still $\frac{\infty}{\infty}$ — apply again:

$\displaystyle=\lim_{x\to \infty}\frac{2}{e^x}=0$

↑ problem
12.

$\frac{\infty}{\infty}$. Apply L'Hôpital:

$\displaystyle\lim_{x\to \infty}\frac{3x^2+5}{2x^2-1}=\lim_{x\to \infty}\frac{6x}{4x}=\frac{6}{4}=\frac{3}{2}$

(This matches the same-degree shortcut from L5 — the ratio of leading coefficients.)

↑ problem

0·∞ Forms

13.

As $x\to 0^+$: $x\to 0$ and $\ln x\to -\infty$, a $0\cdot(-\infty)$ form. Rewrite $x$ as $\dfrac{1}{1/x}$:

$\displaystyle\lim_{x\to 0^+} x\ln x=\lim_{x\to 0^+}\frac{\ln x}{1/x}$

Now it's $\frac{-\infty}{\infty}$. Apply L'Hôpital:

$\displaystyle=\lim_{x\to 0^+}\frac{1/x}{-1/x^2}=\lim_{x\to 0^+}(-x)=0$

↑ problem
14.

Rewrite $x^2$ as $\dfrac{1}{1/x^2}$:

$\displaystyle\lim_{x\to 0^+} x^2\ln x=\lim_{x\to 0^+}\frac{\ln x}{1/x^2}$

$\frac{-\infty}{\infty}$. Apply L'Hôpital:

$\displaystyle=\lim_{x\to 0^+}\frac{1/x}{-2/x^3}=\lim_{x\to 0^+}\left(-\frac{x^2}{2}\right)=0$

↑ problem
15.

As $x\to\infty$: $x\to\infty$ and $\sin(1/x)\to 0$, an $\infty\cdot 0$ form. Rewrite $x$ as $\dfrac{1}{1/x}$:

$\displaystyle\lim_{x\to \infty} x\sin\!\left(\frac1x\right)=\lim_{x\to \infty}\frac{\sin(1/x)}{1/x}$

$\frac00$. Apply L'Hôpital (differentiating with respect to $x$, using the chain rule on $\sin(1/x)$):

$\displaystyle=\lim_{x\to \infty}\frac{\cos(1/x)\cdot(-1/x^2)}{-1/x^2}=\lim_{x\to \infty}\cos\!\left(\frac1x\right)=\cos(0)=1$

↑ problem
16.

Rewrite $\sqrt{x}$ as $\dfrac{1}{x^{-1/2}}$:

$\displaystyle\lim_{x\to 0^+} \sqrt{x}\,\ln x=\lim_{x\to 0^+}\frac{\ln x}{x^{-1/2}}$

$\frac{-\infty}{\infty}$. Apply L'Hôpital:

$\displaystyle=\lim_{x\to 0^+}\frac{1/x}{-\frac12x^{-3/2}}=\lim_{x\to 0^+}\left(-2x^{1/2}\right)=0$

↑ problem

∞−∞ Forms

17.

Combine over a common denominator:

$\displaystyle\frac1x-\frac{1}{\sin x}=\frac{\sin x-x}{x\sin x}$

At $x=0$: $\frac{0-0}{0}=\frac00$. Apply L'Hôpital:

$\displaystyle\lim_{x\to 0^+}\frac{\sin x-x}{x\sin x}=\lim_{x\to 0^+}\frac{\cos x-1}{\sin x+x\cos x}$

Still $\frac00$ — apply again:

$\displaystyle=\lim_{x\to 0^+}\frac{-\sin x}{2\cos x-x\sin x}=\frac{0}{2}=0$

↑ problem
18.

Rewrite in terms of sine and cosine:

$\displaystyle\sec x-\tan x=\frac{1}{\cos x}-\frac{\sin x}{\cos x}=\frac{1-\sin x}{\cos x}$

As $x\to\frac{\pi}{2}^-$: $\frac{1-1}{0}=\frac00$. Apply L'Hôpital:

$\displaystyle\lim_{x\to \frac{\pi}{2}^-}\frac{1-\sin x}{\cos x}=\lim_{x\to \frac{\pi}{2}^-}\frac{-\cos x}{-\sin x}=\frac{0}{1}=0$

↑ problem
19.

Rewrite in terms of sine and cosine:

$\displaystyle\csc x-\cot x=\frac{1}{\sin x}-\frac{\cos x}{\sin x}=\frac{1-\cos x}{\sin x}$

At $x=0$: $\frac{0}{0}$. Apply L'Hôpital:

$\displaystyle\lim_{x\to 0}\frac{1-\cos x}{\sin x}=\lim_{x\to 0}\frac{\sin x}{\cos x}=\frac{0}{1}=0$

↑ problem
20.

Combine over a common denominator:

$\displaystyle\frac{1}{x-1}-\frac{1}{\ln x}=\frac{\ln x-(x-1)}{(x-1)\ln x}$

At $x=1$: $\frac{0-0}{0}=\frac00$. Apply L'Hôpital:

$\displaystyle\lim_{x\to 1}\frac{\ln x-x+1}{(x-1)\ln x}=\lim_{x\to 1}\frac{1/x-1}{\ln x+\frac{x-1}{x}}$

Still $\frac00$ at $x=1$ — apply again:

$\displaystyle=\lim_{x\to 1}\frac{-1/x^2}{1/x+1/x^2}=\frac{-1}{1+1}=-\frac{1}{2}$

↑ problem

Indeterminate Powers

21.

This is $1^\infty$. Let $y=\left(1+\frac3x\right)^x$, so $\ln y=x\ln\left(1+\frac3x\right)$, a $\infty\cdot 0$ form. Rewrite and apply L'Hôpital:

$\displaystyle\lim_{x\to\infty}\ln y=\lim_{x\to\infty}\frac{\ln(1+3/x)}{1/x}=\lim_{x\to\infty}\frac{\frac{1}{1+3/x}\cdot(-3/x^2)}{-1/x^2}=\lim_{x\to\infty}\frac{3}{1+3/x}=3$

Since $\ln y\to 3$, exponentiate: $y\to e^3$.

$\displaystyle\lim_{x\to \infty}\left(1+\frac3x\right)^x=e^3$

↑ problem
22.

This is $0^0$. Let $y=x^x$, so $\ln y=x\ln x$, a $0\cdot(-\infty)$ form (this is exactly Problem 13).

$\displaystyle\lim_{x\to 0^+}\ln y=\lim_{x\to 0^+}x\ln x=0$

Since $\ln y\to 0$, exponentiate: $y\to e^0=1$.

$\displaystyle\lim_{x\to 0^+} x^x=1$

↑ problem
23.

This is $\infty^0$. Let $y=x^{1/x}$, so $\ln y=\dfrac{\ln x}{x}$, an $\frac{\infty}{\infty}$ form.

$\displaystyle\lim_{x\to\infty}\ln y=\lim_{x\to\infty}\frac{\ln x}{x}=\lim_{x\to\infty}\frac{1/x}{1}=0$

Since $\ln y\to 0$, exponentiate: $y\to e^0=1$.

$\displaystyle\lim_{x\to \infty} x^{1/x}=1$

↑ problem
24.

This is $1^\infty$. Let $y=\left(1+\frac2x\right)^{3x}$, so $\ln y=3x\ln\left(1+\frac2x\right)$.

$\displaystyle\lim_{x\to\infty}\ln y=\lim_{x\to\infty}\frac{\ln(1+2/x)}{1/(3x)}=\lim_{x\to\infty}\frac{\frac{1}{1+2/x}\cdot(-2/x^2)}{-1/(3x^2)}=\lim_{x\to\infty}\frac{6}{1+2/x}=6$

Since $\ln y\to 6$, exponentiate: $y\to e^6$.

$\displaystyle\lim_{x\to \infty}\left(1+\frac2x\right)^{3x}=e^6$
