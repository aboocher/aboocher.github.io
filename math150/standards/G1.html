G1: Function Notation & Simplifying Expressions

27 practice problems, roughly ordered from warm-up to challenge within each topic. Work the problems first, then check the Solutions section below.

  • When distributing a negative sign or subtracting a whole expression, distribute it to every term inside the parentheses — this is the most common source of sign errors.
  • Fully expand products like $(x+3)(x-3)$ or $x(x+4)$ before combining like terms.
  • $f(a)$ means "plug $a$ in for every $x$ in $f$" — it is not multiplication.
  • Composition order matters: $f(g(x))$ and $g(f(x))$ are usually different. Work from the inside out.
  • Watch out: $\sqrt{x^2} = |x|$, not just $x$.

$= 2x + 4$

2.

$= x + 15$

3.

Distribute the $-2$: $6x - 2x + 8$.

$= 4x + 8$

↑ problem
4.

Multiply: $\frac{2 \cdot 9x}{3} = \frac{18x}{3}$.

$= 6x$

↑ problem
5.

Distribute both: $5x - 3x + 7 + 2x - 2$.

Combine like terms: $(5x - 3x + 2x) + (7-2)$.

$= 4x + 5$

↑ problem
6.

Distribute: $(x^2 + 4x) - (x^2 - 2x)$.

$= x^2 + 4x - x^2 + 2x = 6x$

↑ problem
7.

Expand each piece: $(x^2 - 9) - (x^2 - x)$.

$= x^2 - 9 - x^2 + x = x - 9$

↑ problem
8.

Expand: $(x^2 + 5x - 2x - 10) - (x^2 + 3x) = (x^2 + 3x - 10) - (x^2+3x)$.

$= -10$

↑ problem
9.

Distribute: $2x^2 - 2x - 2x^2 + 2x$.

$= 0$ — everything cancels. Trust the algebra even when the answer looks "too simple."

↑ problem
10.

Expand both squares: $(x^2 + 6x + 9) - (x^2 - 6x + 9)$.

$= 12x$

Faster route: difference of squares $a^2-b^2=(a-b)(a+b)$ with $a=x+3,\ b=x-3$: $(6)(2x) = 12x$.

Combining, Composing & Decomposing Functions

17.

$f(3) = 3^2 - 2(3) = 9 - 6 = 3$.

$g(-1) = 5 - (-1) = 6$.

$f(3) + g(-1) = 3 + 6 = 9$

↑ problem
18.

Work inside-out. First $f(2) = 3(2) - 4 = 2$.

Then $g(f(2)) = g(2) = 2^2 + 1 = 5$.

↑ problem
19.

Replace every $x$ with $(x+1)$: $f(x+1) = 2(x+1)^2 - 5$.

$= 2(x^2 + 2x + 1) - 5 = 2x^2 + 4x + 2 - 5$.

$f(x+1) = 2x^2 + 4x - 3$

↑ problem
20.

$g(x-2) = (x-2)^2 - 4 = x^2 - 4x + 4 - 4$.

$g(x-2) = x^2 - 4x$

↑ problem
21.

First $g(1) = 4(1) + 1 = 5$.

Then $f(g(1)) = f(5) = \dfrac{5-3}{2} = \dfrac{2}{2} = 1$.

↑ problem
22.

Replace every $x$ in $f$ with $g(x) = 2x-1$: $f(g(x)) = (2x-1)^2 + 3$.

$= 4x^2 - 4x + 1 + 3$.

$f(g(x)) = 4x^2 - 4x + 4$

↑ problem
23.

$f(g(x)) = \sqrt{(x^2-4)+4} = \sqrt{x^2}$.

Careful — $\sqrt{x^2} = |x|$, not just $x$.

Domain: we need $x^2 \geq 0$, true for every real number, so the domain is all real numbers.

↑ problem
24.

Inside operation: "multiply by 3, add 5." Outside operation: "raise to the 7th power."

$g(x) = 3x + 5$ (inside), $f(x) = x^7$ (outside).

Check: $f(g(x)) = (3x+5)^7$. ✓ (Other valid decompositions exist — this is the most natural one.)

↑ problem
25.

Inside operation: "square, then subtract 9." Outside operation: "take the square root."

$g(x) = x^2 - 9$ (inside), $f(x) = \sqrt{x}$ (outside).

Check: $f(g(x)) = \sqrt{x^2-9}$. ✓
