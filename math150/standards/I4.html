I4: Projectile Motion, Displacement & Total Distance

9 word problems on projectile motion, built by integrating acceleration up to velocity and position. Unless stated otherwise, use $a(t)=-32\text{ ft/s}^2$ for gravity.

  • Start from $a(t)=-32$ (constant). Integrate once: $v(t)=-32t+v_0$, where $v_0=v(0)$ is the initial velocity (positive means launched upward, negative means thrown downward, zero means dropped).
  • Integrate again: $s(t)=-16t^2+v_0t+s_0$, where $s_0=s(0)$ is the initial height.
  • The object hits the ground (or water) when $s(t)=0$ — solve that equation for $t$, then plug into $v(t)$ if you need the impact velocity.
  • Maximum height happens when $v(t)=0$ (the instant the object stops rising and starts falling) — solve for that $t$, then plug into $s(t)$.
  • Total distance traveled is not the same as displacement. If the object goes up before coming down, add the upward distance and the downward distance separately: $(\,\text{max height}-s_0\,)+(\,\text{max height}-0\,)$ — don't just compute $s(\text{end})-s(0)$.

Solutions

Dropped Objects

1.

$v_0=0$, $s_0=256$. Integrating $a(t)=-32$: $v(t)=-32t$. Integrating again: $s(t)=256-16t^2$.

Hits the water when $s(t)=0$: $256-16t^2=0\Rightarrow t^2=16\Rightarrow t=4$ (taking the positive root).

Impact velocity: $v(4)=-32(4)=-128$ ft/s

↑ problem
2.

$v_0=0$, $s_0=400$. $v(t)=-32t$, $s(t)=400-16t^2$.

$400-16t^2=0\Rightarrow t^2=25\Rightarrow t=5$ seconds.

Impact velocity: $v(5)=-32(5)=-160$ ft/s

↑ problem
3.

$v_0=0$, so $v(t)=-32t$ and $s(t)=s_0-16t^2$.

Find the time of impact from the given velocity: $-192=-32t\Rightarrow t=6$ seconds.

At impact, $s(6)=0$: $s_0-16(6)^2=0\Rightarrow s_0=16(36)=576$ feet

↑ problem

Thrown Upward

4.

$v_0=128$, $s_0=0$. $v(t)=128-32t$, $s(t)=128t-16t^2$.

Maximum height when $v(t)=0$: $128-32t=0\Rightarrow t=4$.

$s(4)=128(4)-16(16)=512-256=256$ feet — the maximum height.

Since it launches and lands at the same level ($s_0=0$), total distance is twice the max height: $2(256)=512$ feet

↑ problem
5.

$v_0=32$, $s_0=48$. $v(t)=32-32t$, $s(t)=48+32t-16t^2$.

Maximum height when $v(t)=0$: $32-32t=0\Rightarrow t=1$. $s(1)=48+32-16=64$ feet.

Lands when $s(t)=0$: $48+32t-16t^2=0$. Divide by $-16$: $t^2-2t-3=0\Rightarrow(t-3)(t+1)=0\Rightarrow t=3$ (taking the positive root).

Total distance: up from $48$ to $64$ is $16$ ft, then down from $64$ to $0$ is $64$ ft.

$16+64=80$ feet

↑ problem
6.

$v_0=64$, $s_0=0$. $v(t)=64-32t$, $s(t)=64t-16t^2$.

Returns to the ground when $s(t)=0$: $64t-16t^2=0\Rightarrow 16t(4-t)=0\Rightarrow t=4$ (taking the nonzero root).

$v(4)=64-32(4)=64-128=-64$ ft/s

↑ problem

Working Backward From Given Data

7.

$v_0=-24$. $v(t)=-24-32t$, $s(t)=s_0-24t-16t^2$.

At $t=2.5$, $s(2.5)=0$: $s_0-24(2.5)-16(2.5)^2=0\Rightarrow s_0-60-100=0\Rightarrow s_0=160$ feet

↑ problem
8.

Here $a(t)=-9.8$, so integrating: $v(t)=-9.8t$ (since $v_0=0$), and $s(t)=s_0-4.9t^2$.

Find the time of impact from the given velocity: $-58.8=-9.8t\Rightarrow t=6$ seconds.

At impact, $s(6)=0$: $s_0-4.9(6)^2=0\Rightarrow s_0=4.9(36)=176.4$ meters

↑ problem
9.

$v_0=160$, $s_0=0$. $v(t)=160-32t$, $s(t)=160t-16t^2$.

Maximum height when $v(t)=0$: $160-32t=0\Rightarrow t=5$. $s(5)=160(5)-16(25)=800-400=400$ feet.

Returns to the ground when $s(t)=0$: $160t-16t^2=0\Rightarrow 16t(10-t)=0\Rightarrow t=10$ seconds total flight time.

Total distance (launched and landed at the same level): $2(400)=800$ feet
